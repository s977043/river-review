## 改善アクション

### 自動ガードの追加（A）

**`carry-over.md` の AUTO 区画の鮮度を機械的に検査する。** 区画が生成する「記録時刻」が現在から N 日以上古い場合に警告を出します。これは改善が必要なこと 3 に対する唯一の機械的な検知手段で、hook 側の失敗・shebang の差し替え・`CARRY_OVER_SKIP` の付けっぱなしを区別せずに拾えます。

hook は個人環境（`~/.claude/hooks/`）にあり本リポジトリの CI では回せないため、検査は `/orchestrate` の Step 0 に「AUTO 区画の記録時刻を読み、3 日以上古ければ hook の生死を疑う」として置くのが現実的です。**リポジトリ側のガードではなくセッション開始時の測定項目として機構化します。**

### ガードの追記（B）

CLAUDE.md の AI Misoperation Guards に次の追記を提案します。**本 PR には含めていません。** CLAUDE.md の変更は承認が要り、ガードの追加は `docs/development/guard-ledger.yaml` の同時更新も伴うため、別 PR として切り出す必要があります（`Meta consistency` が両者のドリフトで落ちます）。
